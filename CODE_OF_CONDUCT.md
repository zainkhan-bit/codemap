# Code of Conduct

CodeMap adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, welcome newcomers, focus on the work rather than the
person, and accept that maintainers may remove comments, commits or contributors that violate
these standards.

Report unacceptable behaviour privately to the project maintainers through the repository's
private contact channel (for GitHub-hosted copies: a private security advisory or the maintainers
listed in the repository). Reports are handled confidentially.
